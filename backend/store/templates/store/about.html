How it is built

  • Data pipeline (pandas): cleaning, cancellation matching, business metrics.
  • Machine learning (scikit-learn): customer segmentation and a repurchase model with out-of-time validation.
  • Market basket analysis (SciPy sparse matrices): association rules behind the recommendations.
  • Web app (Django): server-side pricing, relational schema with foreign keys, authentication and an admin panel.
  • Payments (Stripe Checkout, test mode): hosted payment page and signature-verified webhooks; card details never touch this server.
  • Tests (pytest) for the pipeline and the web app.
